Rumah Tangga — situs anggaran rumah tangga untuk keluarga Indonesia: ringkasan bulanan, transaksi yang bisa ditambah/diubah/dihapus, anggaran per kategori, tabungan, tagihan, dan laporan tren 6 bulan. Semua angka dalam Rupiah dan saling konsisten; data tersimpan di peramban (localStorage), tanpa jaringan sama sekali.

## Run it

```sh
node serve.ts
```

Lalu buka http://localhost:8080 — atau sajikan folder `app/` dengan server statis apa pun. Halaman: `#/` Ringkasan, `#/transactions` Transaksi, `#/budget` Anggaran, `#/goals` Tabungan, `#/bills` Tagihan, `#/reports` Laporan.
